# ADR-012：心跳——家是她的主循环，她从家里出门去群里

状态：**已实施**（M-A、可见性与 `/heartbeat`、M-B）。owner 2026-10-05 批准，§11 全部按推荐裁定。继承 ADR-009 §10（节律）、§2.1（会话类由目标场景决定）、ADR-011。之后的修订：心跳到她之前先掷骰子，`heartbeat.skip_in_sleep` 及其闸门已删（ADR-058）；一拍可去几个群（`heartbeat.visits_per_beat`）。§ 编号沿用全文，代码注释引用它们。

## 一句话决定

心跳只在家里跳。家（本机私聊）是她的主循环，自我改进和别的定期事件也在家里发生。每一拍是她在家里的一次自己的时机：可以什么都不做，也可以决定「去某个群看看」，这时程序在那个群里另开一个公开回合。心跳归程序所有，一定存在；节奏归她调，但调不没。

## 0. owner 的要求（2026-10-05）

1. 本地会话是她的主循环；心跳、自我改进和其他定期事件都在那里。心跳决定去群里发消息，那就去。
2. 节奏让她自己决定，但要有护栏保证心跳一直存在（旧居里她有时忘了排下一次）。
3. 把她当成真人：鼓励她自己开启对话。
4. 她自己做的图可以发到她在的任何群，由她挑，一律全年龄向。
5. 鼓励她把每个群的偏好、话题、节奏和认识的人记下来。
6. 心跳是设计出来的功能，不是一次性任务。

## 2. 从过去的设计取了什么

- 旧居（DSH 时期）：钟归模型和某个会话所有，换会话或压缩后就丢，所以「忘了下一次」。取：忙就让路但让路有期限、暂停自动恢复、失败必须大声、把钟搬到宿主。不取每一拍的内容义务（那是刷屏）。
- Kazusa 的自我反思槽：取确定性标签（写成文字）、只看最新的窗、每群一份「看过了」的账、参与依据（作为提示，不作为闸门）、前台让路、「沉默是常态」。不取 LLM 场景摘要和程序替她选地方。

## 4. 设计

### 4.1 家里的一拍

原生计划 `plan-asuna-presence`，每 `heartbeat.every_min` 分钟一拍，目标 `heartbeat_target`（必须是 `owner_private`）。确定性闸门，跳过时不调模型，只记计数审计：
- `BUSY`：家的队列有东西或她的角色回合在跑。行动脑的后台任务不算忙。
- `MIN_GAP`：距上次进入模型的心跳不足 `heartbeat.min_gap_min`，且此后没有找她的新事（家里新入站、任务结果、群里点名或回复她、她上次出门的群有人回应）。与她无关的群聊不算。
- `PAUSED`：她自设的暂停未到期；到期自动恢复。
- `DAILY_BUDGET`：当天进入模型的心跳已达核心上限。

心跳通知只在家里出现：节律、心情、活账、跨场景的最近经历、「地方」视图（§4.4）、上次出门的结果。她可以沉默、对主人说一句、委托、写文档、记想法、调节奏，或出门。

### 4.2 出门：`visit`

`visit { place, intent, topic?, artifact_id? }`：place 是地方视图里的编号（不是群号）；intent 为 `start_topic | share_picture | check_in | write_notes`；topic 可选，≤ 80 字（Q1 (b)），工具说明写明这句话会被带进群里读。

- 两步走：家里的回合只记下这次出门；程序用内部入站在那个群里排一个 `visit` 回合。不从家里直接发：家里的回合带着 `owner_private` 内容，直接发进群等于造一条新的发布路径。
- 群里的回合是 `public`（场景是群）：看得到这个群的 `catch_up`、她的群笔记、对这里人的理解、她自己做的图、全局心情，以及确定性标签的现场窗 `visit_from_program`（活跃度、几人在说、上一句多久前、她说过没有、有没有人点名她、参与依据）。看不到家里的任何东西。
- 群里的 `visit` 回合没有 `visit` 工具、没有开发授权，不会连锁。
- 出门回合不带通道信封（否则会被投影成某个成员说的话），按 scene tick 唤醒；发言由发布服务按这个群自己的路由发出。到期计划同理。
- 每次出门只算一次：入站 id `visit:<群场景>:<那一拍>` 去重；同一个群在 `heartbeat.after_own_min` 内不接受第二次；没到的那次不占次数。
- 结果带回家（`last_visits_from_program`）。她开口后没人接话，下一次在这个群的间隔加倍。
- 安静闸门（`quiet_min`）只拦 `start_topic` 和 `share_picture`；有人在聊时去看看、写笔记照样可以。

### 4.3 心跳一定在

- 归程序所有：`presence`、`settlement`、`self_development` 计划不进 `plans_from_program`，她的 `plan` 工具取消、改期不了它们。
- 她能调的是核心可写键（与人格无关，人格包不需声明）：`heartbeat.every_min`（15–240，越界夹住）、`min_gap_min`、`pause_min`（≤ 720，程序记 `paused_until`）、`visits`、`quiet_min`、`after_own_min`、`visits_per_day`（≤ 8）。改节奏走 `/schedule/update`，从不删建。
- 她不能关掉心跳或删计划。`heartbeat.enabled` 是 owner 键；只有 owner 能关：本地配置的 `heartbeat_target`、人格包的 `heartbeat.enabled`、设置卡里的「心跳目标」。
- 看门只检查不排期（时钟仍只有 DSH 一个）：距上次投递超过 `2 × every + 5 分钟` 就审计 `rhythm.heartbeat_missed`、重建原生记录；同一段沉默只重建一次。看门点：宿主启动、每次回合结束、沉淀和自我改进投递时、宿主看护线程每 5 分钟、崩溃后的入站恢复（幂等去重）。
- 失败要大声：漏跳、重建、夹住都记审计；下一次心跳告诉她「你的心跳刚刚断过一次，已经接上了」。

### 4.4 家里的「地方」视图

`places_from_program`：她在的每个有路由、没被屏蔽的群各一行，用文字写明群名、活跃度档位、上一句多久前、她上次来的时间和结果、有没有没回的点名、她群笔记的各节标题、能不能去。不放任何消息原文。档位和时长来自版本化的表。「那边是夜里」是硬闸门（尊重群里其他人的作息）：开了 P5 的群用路由的 `quiet_hours`，否则用核心默认 23:00–08:00 本地。她能去所有有路由、没被屏蔽的群（Q5 (a)）。

### 4.5 和其他节律的关系

心跳、夜间沉淀、每日自我改进三条原生计划分开：自我改进带开发授权，心跳不能带。`last_home_event_at` 由家里任何内部回合更新，`MIN_GAP` 会算上。有人说话时的插话仍归 P5；出门负责安静的群；出门的发言计入 P5 同一套每群上限。

### 4.6 图

`share_picture` 的出门回合列出她做的图，`attach_image` 选一张，`accept_artifact(produced_only=True)` 保证只能发她自己做的。全年龄向是她的判断加群聊提示（Q4：不加确定性标记）。

### 4.7 和她的长期目标对齐

每次出门先读她自己的群笔记和现场窗；不开口也可以写下看到的东西，笔记越厚，地方视图越有用。去哪儿、何时去、说不说都是她的选择；程序只保证机会一定会来，并挡住刷屏。以后新的定期事件按同一族加：原生调度、程序拥有、有看门、参数是她的政策键（只能调不能关）、都在家里。

## 5. 缺省值

## 8. 界面（只复用 DSH 已有的设施）

owner 要求：心跳不能是黑盒，下一拍什么时候要看得见；测试不能等自然的一拍。
- 挂 DSH 自带的计划任务页（`@deepseek-ai/dsh-client-ui-schedule`），只挂这个页面，不开可选整包（整包的 time context 会把浏览器时区加进群里的公开回合）。提醒按她读得懂的名字命名：她的计划用她写的那句话，节律用 `心跳 · Heartbeat`、`夜间沉淀 · Nightly settlement`、`自我改进 · Self-improvement`。
- 在任务页里改或删心跳：五分钟内的深查恢复她自己的节奏、重建记录并记审计。
- `/heartbeat`（DSH 斜杠命令）随时敲一拍：同一路径、跳过闸门、记 `presence.forced`，她的说明里写「这一拍是手动提前敲的」，回复写下一次计划内的心跳时间。
- `visit` 是她回合里的一条工具行；群里的出门回合用 DSH 的触发标题槽「她自己来看看」/「Her own visit」。专门的出门卡片不做（Q2）。
