# ADR-121: A model chosen for one session has no end

Status: **Proposed** 2026-11-09 (laid down; not designed, not built). The owner's idea of 2026-11-07, to be drafted
once most ADRs had closed.

## 1. The gap

DSH's per-session model picker, shown on her sessions, pins a session to the chosen model for good, with no way back
to the program's route. The owner's own test pin on one of her QQ sessions (2026-10-25) still holds. The root gap is
in the lifecycle: a deliberate selection is created and used, but never ends. The owner suggests removing the widget
from her sessions.

## 2. Closes when

No session of hers stays on a model that nobody has chosen for it now. Either the widget is gone from her sessions,
or a pin has an end (a visible way back to the program's route, or an expiry); in both cases the existing pins are
found and cleared with the owner. Shown first in an isolated review profile, then on her profile.

## 3. Undecided (the owner's)

- Remove the widget, or give a pin an end. The widget is DSH's shipped UI, so removing it on her profile needs his
  approval.
- Whether this is an Asuna setting or a change on his DSH fork (DSH upgrades are his).
- How many of her sessions carry a pin today: counted first, read-only.
