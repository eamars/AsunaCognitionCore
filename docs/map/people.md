跨场景只读联动（A2）：一条有向边 + 一个 canonical person，配置是唯一真相。

- def `context_links` — {场景: [可只读的场景]}。顶层 context_links 与路由级 read_scenes 都算，两处都不做通配。
- def `readable_scenes` — 这个场景可以额外只读哪些场景（有序、不含自己）。
- def `read_scope` — 这一轮能读哪些场景／scope_key：本场景永远排第一，联动场景按配置顺序跟在后面。
- def `scene_id_filter` — 场景过滤条件：没联动时保持原来的单值形状（查询条件一行都不多写），联动了才换成 $in。
- def `sync_scene_docs` — 把派生出来的 readable_scenes 写进 scenes 文档（只为可观察；读路径现算自配置）。
- def `canonical_map` — {别名 person_id: canonical person_id}；自指与非字符串条目照实丢掉。
- def `canonical_person_id` — 别名 → canonical，只看配置；没配映射就是本人 id。db 参数保留给调用方签名，不读。
- def `person_classes` — {person_id: [同一个人的全部 person_id]}：只包含真的不止一个人的那几组，含本人。
- def `extra_person_values` — 按人过滤时要一起算进来的其他 person_id（同一个人的其他入口）；没有就空。
- def `relationship_target` — 这个人在这一轮的关系／偏好状态该落在哪一份 head。
- def `message_times` — {消息 id: (时间, 时间来源)}：出站行内 receipt_at ＞ 关联出来的 sink_receipts.received_at ＞ 入站 occurred_at ＞ 落库 received_at。

- def `owner_private_scope`

## `private_words`

[src/asuna/private_words.py](../../src/asuna/private_words.py)

Words that point at real people and places, kept per deployment and never committed.

- class `PrivateWordsError`
- def `path` — The deployment's list: ASUNA_PRIVATE_WORDS, else <data>/private/personal-words.txt.
- def `parse` — [(line_number, category, word, why)] of the well-formed entries.
- def `load` — The entries, or None when the deployment has no list.
- def `problem` — Why an entry can't be kept, in words; None when it can.
- def `pattern` — A Latin word matches as a whole word (case-insensitive); other text matches where it appears.
- def `find` — [(entry line number, category)] of the entries found in a text, each once.
- def `add` — Keep an entry; the same word is kept once (at home its category and reason are replaced).
- def `remove`
- def `summary` — How many entries per category; never the words.
- def `run` — The tool, for either brain: what it did, never a listed word.
