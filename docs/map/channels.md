## `vision`

[src/asuna/vision.py](../../src/asuna/vision.py)

入站图片元数据与行动脑 DSH ``read_image`` 接线。

- def `ref_of` — 附件的稳定引用：同一场景同一条消息同一段图片，重算不变，也不暴露平台 ID。
- def `media_block` — adapter 注入的规范化媒体块；没有就 None。宿主不解析 OneBot raw，只认这个命名空间。
- def `host_allowed` — 白名单：精确主机名，或以点开头的条目允许其子域。大小写不敏感。
- def `sniff_media_type` — 只认魔数。声明的 content-type 只作为附带信息，不作为依据。
- def `path_form` — 'task' 是 /task/…（行动任务自己的工作区），'absolute' 是本机绝对路径，别的都不是路径。
- def `file_field` — 消息写的那个文件：裸文件名照旧截到 120 字，路径形态留足长度（不然长路径会被截成另一个文件）。
- def `local_uploads` — Pictures the owner attached in her local chat → her images in that chat (BlobStore, kind image) and the media block her input row records, the same shape a platform adapter writes.
- def `local_upload_item` — A picture the program stored itself from the owner's local chat: never a platform message's claim.
- def `vision_capability` — 这条模型路由现在到底能不能收图：只看配置声明，不看模型名字。route 是 executor（行动脑）或 character（角色脑）。
- def `sticker_kind` — 'market' (a store sticker the platform can send again by its ids), 'custom' (a picture sent as a sticker: kept by its bytes), or None (a photo).
- def `attachments_of` — 一条消息 → 有界附件清单（只列图片；其它类型只保留占位符事实）。
- def `readable_image_scenes` — 本任务能读图的范围：本场景（围栏照旧）+ 配置声明的只读联动场景（A2 同一口径）。
- def `scene_attachments` — 本场景（外加按配置只读联动的场景）最近的入站图片。范围由任务绑定，参数换不了它。
- def `scene_id_of`
- def `pull_bytes` — 按元数据把图片字节拉回来。返回 (bytes, media_type, via, source)。失败一律抛真实错误码。
- def `resolve_image_file` — 路径 ref 指的是哪个文件：``/task/…`` 落在本任务自己的工作区下，绝对路径照原样拿。
- def `read_image_for_task` — read_image 的实际执行：场景围栏 → 能力核对 → 拉字节 → 落 BlobStore → 交给插件的视觉输入载荷。
- def `path_image` — Read a picture from this machine's disk (home conversations only): the bytes are this call's real visual input, and the file it came from is recorded as the artifact's source (``file:<绝对路径>``).
- def `stored_image` — Look again at a picture already stored as an image artifact: one in this scene's own scope, one she made herself (her own generator, any scene), or one this turn was offered to send.
- def `local_upload_bytes` — A local-chat picture's stored bytes, re-checked against the row that records it: the row must be the program's own local input (no platform envelope), and the artifact must be in that row's scope with that input as its source — a platform m
- def `media_source_url` — URL 不进清单（避免把带 rkey 的临时链接长期抄进上下文），拉取时按原消息回读。
- def `task_attachment_context` — 行动任务输入里的附件段：让她知道有什么可拉、ref 是什么、没拉过就是没看过。
- def `line_refs` — The refs of a platform line's readable pictures, as a short note under the line in her conversation: the placeholder says a picture was there, the ref is what read_image takes.
- def `media_note` — 给角色现场的附件元数据：不把图片字节放进上下文。
- class `VisionService` — broker 侧入口：每次调用绑到调用任务自己的场景与纪元，字节复用既有 GridFS BlobStore。
  - `read_image`
- def `route_filtered_tool_names` — 任务能力清单按行动路由的真实能力裁剪：路由不收图时 read_image 不进清单。
- def `inline_summary` — 写进 artifacts 回执的有界副本：字节已在 GridFS，回执里不留 base64（普通 BSON 行 1 MiB 上限）。

## `outbound_media`

[src/asuna/outbound_media.py](../../src/asuna/outbound_media.py)

出站图片附件：她的 attach_image 工具 → SPEAK 行上的元数据 → 通道字节端点 → 已送达历史。

- def `sha256_of`
- def `sniff_media_type` — 只认魔数，和 vision.sniff_media_type 同一张表（离线用例逐条比对，防两处漂移）。
- def `parse_supports` — ``?supports=image,voice`` → ``['image','voice']``；老适配器不带这个参数就是空。
- def `supports_image`
- def `descriptor` — 行上那份附件元数据（校验过的副本）；形状不对就当没有，不猜。
- def `declared` — 这条 publication **现在**到底有没有声明「随这条消息发一张图」。
- def `attachment_for_speak` — 这一轮被程序接受的那张图 → SPEAK 第一行要写的元数据（没有就 None）。
- def `route_target` — 这个场景的路由目标类型（dm / group），没有渠道路由就是 None。
- def `group_scene` — 一个真正的群：场景是群，路由目标也是群（配置把私聊路由成群的不算）。
- def `produced` — 她自己做出来的图：从她自己的生成端点导入时登记的（import_register）。
- def `target_allowed` — 收件方向：任何一个私聊（路由 dm），或她在的任何一个群。主人的私聊能发这一边读得到的图；群和别人的 私聊只发她自己做的图（own_only，owner 2026-10-06：家往外不担心，发什么由她判断）。
- def `own_only` — Only pictures she made go here: a group, or anyone's chat that is not the owner's.
- def `row_own_only` — own_only for a stored outbound row, recomputed from the row's own scene and route.
- def `produced_images` — 她做出来的图（不分场景），新的在前；群聊回合里只列这些。
- def `own_pictures` — Her own newest pictures, to look at where none can be sent (her local chat): ids and when, in words.
- def `image_scopes` — 这一轮能引用哪些场景里登记的图（本场景永远排第一）。
- def `row_is_group` — 这条消息是不是发往一个群：按行自己的场景与路由现算。
- def `row_image_scopes` — 这条消息那一轮能引用哪些 scope：全部从行自己算（场景、路由上的人、session_class）。
- def `image_artifacts` — 本轮可引用的图片：这些 scope 里已存好的 image artifact（新的在前，最多 limit 条）。
- def `offer` — 上下文里那块 ``image_artifacts_from_program``；方向不允许或没图可引用就不出现。
- def `accept_artifact` — 程序接受一张图准备随这条消息发出去：读一次字节、认魔数、按行内 sha 复核。
- def `kept_sticker` — This row sends a sticker, and its picture is one she keeps on her shelf.
- def `serve` — 字节端点的围栏：只发这一条 publication 自己声明的那张图，且行内 sha 复核通过。
- def `register_imported_image` — 把刚导入的字节登记成这个 scope 里的 image artifact；不是图片就什么都不做。
- def `import_register` — 给 ``import_integration_artifact`` 的登记回调：只登记到这个任务自己绑定的 scope。
- def `receipt_evidence` — 平台回执里那份附件证据（适配器真的取到并发了图才会写）。行里没带就按 _id 窄取一次。
- def `sent_attachment` — 这条已送达消息真的带出去的那张图；没有就 None。
- def `history_slot` — 历史行上的附件位：让她看得见「我发过这张图」，也看得见图没跟着出去。
