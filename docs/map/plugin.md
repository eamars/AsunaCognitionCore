## `outage.js`

[packages/cognition-core/src/outage.js](../../packages/cognition-core/src/outage.js)

The span she was down while the Host ran on (ADR-101). Only this plugin knows why a worker went away (a start that failed, a worker that exited), so it keeps the open span in the profile's data folder, `worker-down.json`: {since, cause, tries, inside, opened}. A file and not the database, because the failure is often the database itself, and a file survives a Host restart and a recreated container (the data folder is the deployment's own). The worker reads it at its start (a lease left behind inside the span is that same outage) and never writes it. A completed start hands the span to the worker (`host.came_back`), which records it once as a `worker_down` row (host_stops.py); then the file goes. A worker without that method (an older core) leaves the file for a later one.

- def `FILE`
- def `KEPT`
- def `startCause` — A failed start's cause by name only, as faults.cause takes it: the error code its last line carries, else the exception's class (`AutoReconnect` from "AutoReconnect: <host>:<port>: …").
- def `exitCause` — A worker's exit by its code (`exited:1`, `exited:none` when it had none), or unknown.
- def `openSpan` — The open span, or null when there is none or its file cannot be read.
- def `wentDown` — A worker went down unplanned: open the span, or keep its start and first cause and count one more try.
- def `stopInside` — A Host stop inside the open span (a lease left behind that was not this Host's own exited worker): one more.
- def `cameBack` — A start completed: hand the open span to the worker, then remove it.

## `roots.js`

[packages/cognition-core/src/roots.js](../../packages/cognition-core/src/roots.js)

No local root of this computer reaches her character brain (ADR-098). The worker builds the root table at its start (local_roots.py) and hands it over with its `initialize` answer; every request of her lanes (her persona preset, the relevance gate, the appraiser, the background summaries; never the action brain) is rewritten with it at DSH's `llm/stream` waterfall, the one place every request passes: turn steps, compaction summaries, one-shot sessions. Text blocks (the system message included), reasoning and earlier tool calls' arguments are contracted; storage stays raw. Without a table her lanes' requests are refused with a coded fault, never sent raw. The same shared case file (tests/fixtures/path_placeholders.json) runs here and in pytest.

- def `HER_LANES` — Her lanes (index.js laneOf): whatever the model reads there is hers.
- def `MISSING`
- def `compile` — The worker's wire table, compiled; null for none.
- def `contract` — { text with every root written as its placeholder, how many were replaced }.
- def `rewriteRequest` — { request, count }: the request with every root contracted; the same request object when there was none.
- class `Roots` — The table, its counts and the refusals, kept on the core (`core.roots`).
  - `take` — The worker's answer at its start: a table, or why there is none.
  - `count`
  - `flush` — The counts since the last flush reach the worker, which keeps them for her weekly reading.
  - `refuse`
  - `status` — For the settings card: the table's size, or why there is none; requests rewritten per session since start.
- def `wrapHostPaths` — DSH's fs service, its host-path mapping wrapped once: inside one of her requests the mapped path comes back contracted.
- def `rootsAtTheModel` — The listener: her lanes' requests rewritten, or refused without a table; every other request passes as it is.

## `tiers.js`

[packages/cognition-core/src/tiers.js](../../packages/cognition-core/src/tiers.js)

ADR-075: her action brain's two routes. A job she sent to 高 runs on `routes.actionHigh` until a request there ends in an error DSH's own retries could not cure; then the job falls to the action route for good. What the failure was decides whether 高 rests: a failure of the line rests it for 高's own idle minutes (its cache is gone by then anyway), one that waits on the owner (key, credential, quota) rests it with no clock, and a refusal of this job's content does not rest it at all. Routing goes by DSH's failure codes, never by parsing a message.

- def `failureClass` — What a failure on 高 was: 'owner', 'busy', 'down', 'refused' (anything else that ended the request), or null.
- def `restFor` — The rest a failure starts: null for a refusal; no clock when it waits on the owner.
- def `resting` — Whether 高 is resting now.

## `ui-language.js`

[packages/cognition-core/src/ui-language.js](../../packages/cognition-core/src/ui-language.js)

The language of the names the program gives what DSH shows as plain text: her rhythm tasks in the task page and the scheduler session's title. DSH translates only its own shipped names, so these follow the language of the browser that last opened the Web UI (client.js reports it, and again on a switch). The words are this package's own (locale/<language>.json, `asuna.titles`); a language without a file falls back to English. The choice is kept beside the worker's data so a start uses it before any browser reports.

- def `languageWords` — The words for a language id such as `zh-CN`: its base language when the package has it, else English.
- def `savedLanguage` — The language last reported, or English.
- def `applyLanguage` — A browser reported its language: keep it, give the worker the words (it renames her rhythm tasks) and rename the scheduler session.
