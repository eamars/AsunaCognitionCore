# ADR-006｜实际页面核对

> 范围修订：第 1、10 项的“完整原生导航/Chat”改为固定版公开基础组件的 Asuna 业务组合。报告必须使用“原生基础组件复用＋Asuna业务组合”，不可称完整 WorkspaceBrowser/Chat 接入。

这些是用户可见结果，不是新的运行时门槛。一次自然对话可以覆盖多项；不要求重复采样、不对跑裸 DSH 模型、不向 QQ 制造测试消息。浏览器必须打开现有真实服务，不是演示页。

| 项目 | 在页面检查的结果 |
|---|---|
| 1. 导航与检查器 | 左栏用公开 Input/Button 组合原有场景搜索、选择和只读语义；右侧原检查器的筛选、条目选择、正文与来源仍可用。没有第二套侧栏。 |
| 2. 安静状态 | 页面无新的运行事件时不显示双脑卡、活动计时器或空 Thinking 区。历史可正常阅读；打开页面不启动模型。 |
| 3. 真实正文实时可见 | 一次实际调用结束前能看到文本逐步增长。MONOLOGUE 显示实际人物独白，不是“原始 provider response”或事后摘要。 |
| 4. 原位与归属 | 对同一条生成，在开始、部分内容、完成后观察同一个 node/key；最终文本不重复。新用户消息或切换场景不会把旧流归给新消息。 |
| 5. 双脑／工具／咨询 | 有发生才显示相应来源。实际工具沿原生行呈现；CONSULT 在相关调用下可查，不另建公开 QQ 消息，不为了测试强迫每轮咨询。 |
| 6. 诊断去重 | 默认关闭，不抢正文位置。展开后仅见真实非内容元数据，不重复已显示的思考、正文或工具内容；完整原包仍在既有审计。无法取得就显示具体缺项，不重新请求模型。 |
| 7. 滚动、输入与焦点 | 底部跟随实际增量；上滚/选中文本不被 token 抢走位置；新消息仍按原来队列语义接收。检查器选择不被每个 token 重置。 |
| 8. 结束与停止 | 已完成、截断、失败或停止都使用真实状态；已有部分正文保留。停止当前生成绝不调用停止整个宿主端点。 |
| 9. 观察断线与恢复 | 暂断浏览器观察连接不取消 agent；恢复后补当前真实状态，无任务/输入/工具重发。历史不播放打字动画、不反复显示“新”。 |
| 10. 原生复用与瘦身 | 报告使用“原生基础组件复用＋Asuna业务组合”，列真实包名/slot，并能定位到使用；不声称完整 WorkspaceBrowser/Chat 接入。没有复制私有组件、平行 v2 工作台或新流式框架。已替代且无调用者的旧渲染分支被移除。 |

## 验证方式

1. 本地固定版原生 Chat 作为控件参考，当前 Asuna 页面作为实施前后对照；只对界面，不对模型能力。
2. 用一次真实自然交流看生成中和生成后，用一项已有实际任务查看行动正文。出现何种合法工具序列由模型决定。
3. 断连/片段结算/重复事件等确定性问题可以用现有 UI 测试或标注的流样例；不要为每个分支跑真模型。
4. 对失败/停止可沿已有错误记录与局部测试，真实取消只用可中止的明确任务，不停已有 QQ 服务凑截图。
5. 查看页面标识、非空内容、console 错误、滚动和真实交互；至少保留一张生成中、一张完成后截图。浏览器或录屏可证明正文在完成前增长，单张最终截图不能证明流式。

截图沿本地现有视口；不把移动端重设计、所有浏览器矩阵或像素评分平台加入本轮。确有文字截断/溢出时修实际问题。

## 允许的阶段性状态

原生组装或资料缺口可以如实标 PARTIAL，但不得把手绘相似组件、原包实时刷新或一段录像回放称为本任务完成。不能用“正在等待用户确认另一方案”冻结原来的 agent 工作。

## 交付说明只需短段落

实际入口；本次原生控件/slot；可见改善；已去掉的多余 UI 分支；真实浏览器证据；仍未完成的一处具体缺口。
