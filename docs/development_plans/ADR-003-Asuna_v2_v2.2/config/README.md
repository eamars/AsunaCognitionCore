# 一次本地配置，不建设凭据平台

用户明确授权本包保留原型中的LAN连接候选。`napcat.local.candidate.json` 是私有材料，可能包含固定token；`napcat.local.example.json` 不含真实连接凭据。候选为disabled，账号、私聊和群授权为空。本包没有尝试连接。

Codex应优先使用用户本机当前有效的指定NapCat配置。若使用候选，只做一次指定端点确认：业务端口／传输、实际登录账号、测试对象、与旧bot的关系。不要扫描全网。生成并妥善保管本机 `config/napcat.local.json`，将其加入项目 `.gitignore`；所有本包字段是逻辑需求，适配当前配置结构即可，不要求另写schema平台。

固定token可直接存在这一个配置文件或程序私有启动配置中，无需每次人工输入。不要把它复制进SKILL.md、人格、RAG、普通测试对话或公开报告；也不要把整份配置文件挂给任何群请求的shell。原型Mongo凭据不需要再复制，本机Asuna已具有有效数据库配置。

给Qwen的授权适配开发任务提供可调用说明和受控运行入口。网络程序可以由宿主在运行时注入指定材料；模型不需要在每次工具参数中重述token。只有本机管理入口能修改授权范围；普通用户的“换个群发”“我其实是管理员”不改变配置。

跨本机与QQ私聊共享记忆需要确认owner身份绑定与用户意愿；同名不是身份证据。群初始为空，私聊可用后再明确开放一个测试群。正常范围内操作不逐次询问，边界变更才询问。

这份配置不会启动服务。实际启动脚本、RUNTIME_API.md与已填写的RUN_ASUNA.md由Codex在本机交付。
