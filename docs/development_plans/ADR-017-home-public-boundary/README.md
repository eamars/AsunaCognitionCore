# ADR-017：家与外面之间，什么能过界、怎么过

| 项 | 内容 |
|---|---|
| 状态 | **规则与收紧已实施**（2026-10-06，owner 决定）；「代办」（errand）是**提议**，等 owner 定两项 |
| 日期 | 2026-10-06 |
| 作者 | 实施者（Claude），应 owner 的要求起草 |

「家」= owner_private 的会话：本机对话、主人的 QQ 私聊（`visibility.session_class` / `owner_private_scenes`）。
「外面」= 其余一切：群、别人的私聊、旧居那条线（对方不是主人）。家里的回合权限最大（跑代码、改自己、自开发），
所以「外面的话怎么进家」是安全上要紧的方向。

## 0. owner 的规则（2026-10-06）

1. **家 → 外面**：owner 不担心。仍然只让明确、小块的东西过去（下表），这样漏了什么能说清是谁、为什么过去的。
2. **外面 → 家**：**不能实时**，只能走**她自己审过**的路，并且留在**她自己的记录**里。来源是 ADR-011 Q7（2026-10-05，
   owner 已答）：「别处的影响可以有，但不能直接：只在自我改进的回合里，整理、审过，作为她自己的想法」——今天把它
   从「想法本」推广成家与外面之间的总规则。
3. 理由：外面的人能写任何话，包括冲着她写的「指令」。原话一旦在家里那一轮出现，就是一条进到最高权限上下文的
   提示注入路径。经她自己的话转述、隔夜、留痕，三道一起把这条路堵住。

## 1. 外面 → 家：现在有哪些路

| 路 | 过界的是什么 | 多快 | 审与留痕 | 状态 |
|---|---|---|---|---|
| 想法本 `note_idea` → 自我改进回合 `review_idea` | 她自己写的一句话 + 来源引用（不抄对方原话） | 自我改进回合 | 每条决定（采纳/暂缓/放弃）带理由存档 | 合规则（ADR-011 §6.2） |
| 夜间沉淀 `promote_memory` | 候选摘录（可来自群的记忆）→ 她写的事实/评价/信号 | 每晚一次 | 配额、≥2 个回合 ≥2 个日期的来源；**2026-10-06 起必须写 `why`**，存进记忆并记 `memory.promoted` 审计 | 合规则（本 ADR 收紧） |
| 心跳/自我改进回合的 `recent_experience_from_program` | **2026-10-06 起**：私人对话里的全部来往；群、别人的私聊、旧居线里**只列她自己说过的话**；外面来的任务只给标题和状态，不给行动脑报告的开头 | 每次心跳 | 不再有别人的原话 | 收紧后合规则（之前每拍都带群里原话，违背规则 2） |
| `places_from_program`、`last_visits_from_program` | 各群的情况与出门结果，**只有词**（多热闹、多久没人说、有没有人叫她、她的笔记标题） | 每次心跳 | 固定词表，没有任何人的原话 | 合规则（ADR-012） |
| 心跳唤醒的触发 | 只是「群里有人叫了你」这个事实 | 实时 | 不带内容 | 合规则 |
| 联动场景（`context_links` / route `read_scenes`） | 被联动场景的原话，每轮 12 条 | 每轮 | 只靠配置；`visibility` 只拒「私人读进公开」，**不拒家读群** | **潜在缺口**：今天只联了本机 ↔ 主人私聊；若有人把群联进家，就是实时通道。见 §4 |
| 家里的历史查询（行动脑 `query_authorized_history` 等） | 她主动去拉的原话，行动脑的报告回到家里 | 按她的要求，实时 | 工具回执存档 | **待定**：拉取不是推送，但仍是实时进家。见 §4 |
| 记忆检索 | `global-safe` 记忆（含她提升成公开的）、本场景、owner_private | 每轮 | 群场景的记忆不检索（除非联动） | 合规则 |
| 表情包架子 | 收来的表情包字节（`global-safe`）和**她起的名字、她写的用法** | 她收的时候 | `sticker` 工具；名字和用法是她的话 | 合规则（ADR-016）：家里只看到她的名字 |
| 群里交出去的任务的回报 | 回到**那个群**的回合，不回家 | — | — | 合规则 |

## 2. 家 → 外面：现在有哪些路

| 路 | 过界的是什么 | 限制 |
|---|---|---|
| 出门 `visit` | 她写的 ≤80 字话头、可选一张她自己画的图 | 次数/冷却/夜里；群里那一轮看不到家里的历史、关系、记忆（ADR-012 §4） |
| 群里发图 | 只有她自己做的图，或她架子上的表情包 | 字节端点再核一次（`outbound_media.serve`） |
| 人格与文档 | 只渲染这一类会话读得到的节（`readable_sections(…, session_class)`） | owner_private 的节不进公开回合 |
| 群笔记 | 只在那个群的回合里写、读 | — |
| 队形叫她（ADR-016 后续，d037f5ad） | 不带家里任何东西 | 群里那一轮照常 |

## 3. 实施（2026-10-06）

- `context.py`：`recent_experience_from_program` 的消息查询改成「私人场景（`owner_private_scenes` ∪ 本场景）的来往 +
  所有路由场景里她自己已送达的话」；外面场景的任务去掉 `report_start`；说明里写明外面的东西要带回来走想法本或沉淀。
- `role_tools.py`：`promote_memory` 新增必填 `why`；记忆单元带 `why`；写入时记审计 `memory.promoted`（why、来源、scope）。
- 测试：`test_adr012_visits.py::test_at_home_other_peoples_group_lines_do_not_arrive_live`；`test_adr009_p5_rhythm.py` 的提升用例带 `why` 并查审计。
- 副作用（如实写）：旧居那条线的来往也不再出现在家里的心跳里——对方不是主人。她和旧居照常在那条线里说话。

## 4. 待定 / 没做的

1. **联动场景的潜在缺口**：建议在配置校验里拒绝「家里的场景联动读一个非私人的场景」。今天没有这样的配置，没动。
2. **家里的历史查询**：她（经行动脑）主动拉外面的原话是实时的。可以留着（主动拉、有回执），也可以改成只回她的转述。等 owner 定。
3. **代办（errand，提议）**——主人在家里让她去别处说一句：
   - 只能由主人发起（本机或主人私聊，按 canonical person 判，不看名字）；群里任何人都不能让她转告或代发。
   - 程序在目标会话开一轮（像出门）：那一轮只看到目标会话自己的上下文，加上**主人的原话请求**，标明是主人的。
     家里的历史、关系、记忆都不过去。
   - 回家的只有程序写的状态（发了 / 她不发，带一句理由 / 失败），**不带任何人的回话**；回话按 §1 的路，经她自己的话、隔夜。
   - 目标只限她已有路由的群和私聊；每天有上限；每次留审计。
   - 等 owner 定：要不要「原样转发」（她仍能拒，前面带「主人让我转告」）；私聊别人是否开放，还是只开群。
