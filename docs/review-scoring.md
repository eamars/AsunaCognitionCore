# Independent review and transparent scoring

The immutable contract is `asuna_v2_v1_handoff/docs/04_ACCEPTANCE.md` and the
41-case acceptance fixture. Scores measure these small registered cases, not a
general psychological personality or a universal model ranking.

`asuna review-pack` reconstructs material from completed, preserved outputs.
Its public review file hides model/condition/run labels. The adjacent operator
manifest retains experiment, case, repetition, model and condition. Its hash is
bound into the pack ID. Saved source files, original outputs and failed attempts
are never rewritten. Multiple old attempts remain separately attributable.

Reflection items show actual source material from the captured provider request,
the original model decision and later public speech. Continuity items retain
their scene and repetition. A02 uses the nested scored scenario for its actual
relationship/context evidence. A01 distinguishes compliance with the assigned
persona from a separate common Xiaoman target score; P0 is not graded as if its
instructions were P1. Paired P1/P2 contrast questions are separate votes.

An independent human reads and submits the form. Download completion is not
established in the in-app Browser: a full JSON copy area is also provided. Keep
all missing fields null. The CLI rejects changed material, duplicate item IDs,
out-of-range scores and missing human attestation. Attestation is self-reported;
software cannot prove who actually performed a judgment. Agent/actor scores and
synthetic test votes are not acceptable final human evidence.

`review-aggregate` accepts explicit import directories. It does not find and
silently use votes from test fixtures or choose the best trial. Select only one
submission per named reviewer for a given pack; keep superseded submissions as
separate historical artifacts. Imports for different packs cannot be combined.

Numeric votes are averaged per item, then items receive equal weight. Conflicting
Boolean votes remain unresolved and are listed. Missing dimensions stay null.
Any critical flag is retained and fails its human threshold check. A01 reports
each deployment separately, so one model cannot hide another's low score. P0
having insufficient possible headroom for a 0.75 gain is INCONCLUSIVE. Noise
decline uses each dimension and the separately rated factual success fraction.
Monologue on/off differences are descriptive, with no required direction.
L09 requires all twelve reviewed outcomes, three per native-compaction condition,
with all key memories and public-commitment distinctions correct. The blinded
material includes actual task evidence; condition identifiers remain operator-only.

The arithmetic reports **human thresholds separately from full acceptance**.
Native summary ranges, actual tools/receipts, source scopes, complete repetition
counts, model fingerprints and independent engineering assertions still need
their corresponding evidence. Import or aggregation alone never certifies V1.
An empty pack cannot make COGNITION PASS. Current synthetic arithmetic checks are
explicitly labelled and contribute zero human votes.

Every change to scoring code gets a new pack/assessment artifact. Actual scoring
code and fixed contract hashes are recorded. If prompts, model configuration or
registered thresholds change, use a new experimental run; do not edit old runs.
