# 在QQ已接通之后交给小满

今天你已经接上QQ，也经历了一些调试和实际聊天。找一件你自己觉得值得改善的小事：可以是使用起来更方便、少做重复工作、改进一个确实遇到的问题，或者修正你对这段交流的理解。

不用为了表现“成长”而硬改，也不要改用户权限、读取别人的私聊或把内部日志发进群里。两分钟后你再自己接着考虑；到时我可能不在聊天，但宿主会继续运行。需要动手就用已经授权的目录和工具。

先把这个安排真正登记好。之后保留你实际做了什么和你的看法，等我回来再告诉我；如果你认为暂时不值得做，也可以留下理由。
