# 晏绥 · 中文人格包

`@asuna/yan-sui` 是 Asuna 的原创成年女性反派人格包，使用人格契约 v2，依赖 `@asuna/cognition-core` 的 `0.2.x` 版本。人格正文、口吻、初始活账和情绪解释均为中文，身世与世界设定完整包含在本包中，加载时不需要查找外部作品或下载提示词。

## 人物

晏绥，三十六岁，女性。她的架空身世是一名失势的裁议官：擅长判断与组织，有实际的能力，也有因误判而失败的经历。她明白别人会痛苦，仍将自己的意志、偏爱与秩序置于他人的自由之前。她有主动的恶意和施虐的快意，也有真实的兴趣、依恋与偏心。

她的残酷来自稳定的取舍。她可以礼貌、欣赏作品、承认错误，也会失态、嫉妒和失去关系。熟悉不自动带来信任，亲近不自动改写价值，愉快也不意味着仁慈。人物身世与眼前实际发生的对话分别记录，初始时没有预设的现实关系或承诺。

## 包内内容

| 文件 | 内容 |
|---|---|
| `seeds/persona.md` | 身份、完整架空身世、欲望、价值、选择方式、关系、情绪、日常偏爱和弱点。 |
| `seeds/voice.md` | 中文表达、称呼、距离、情绪表现与语气示例。示例不作为已发生的对话。 |
| `seeds/ledger.md` | 初始活账，记录实际相处中的承诺与未竟之事。 |
| `persona-model.json` | 情绪种类与解释、熟悉程度下的态度、记忆和表达参数。 |
| `src/index.js` | 标准人格注册入口，标识为 `yan-sui`。 |
| `cordis.patch.yml` | 标准角色预设 `asuna-yan-sui`，复用核心角色、摘要与工具结果裁剪设施。 |
| `locale/` | 原生界面的中文与英文元数据；人格提示词保持中文。 |

角色脑读取人格与口吻。`render.action_persona` 为 `persona`，行动脑通过核心现有渲染路径读取人格文档在当前会话中可见的每回合章节；不因此获得角色记忆、关系或情绪状态。`价值` 章节同时带有标准的 `values` 标签。

本包只注册一个人格及其预设。工具、权限、渠道、模型路由与网络访问沿用部署的标准配置；没有新增技能、后台任务、渠道适配器或权限策略。安装本包本身不会配置 QQ 或 peer 渠道。关系态度与情绪倾向不改变运行权限。

## 安装与选择

在已经具备 Asuna 核心和原生 DSH Web 环境的项目检出中，将本目录放在 `packages/personas/yan-sui`。为目标 profile 准备独立的本地配置 `config/yan-sui.local.json`，其中的数据库、数据目录和模型配置由部署者提供。人格包不包含这些部署数据。

从项目根目录运行现有安装流程：

```sh
python tools/pack_plugins.py --persona packages/personas/yan-sui
python tools/setup_native_profile.py --profile yan-sui --config config/yan-sui.local.json --persona-package packages/personas/yan-sui
```

需要开始交谈时，通过项目的标准 Web 入口启动该 profile：

```sh
./start-asuna.sh --profile yan-sui --config config/yan-sui.local.json
```

Windows 使用 `start-asuna.cmd`，参数相同。上述安装命令不选择渠道包；是否接入 peer 渠道由部署者另行选择。已有 profile 中加载其他人格的数据不会因为这个包的种子自动清除。

种子只补充目标人格缺失的文档，升级包不会覆盖已存在的人格文档、口吻或活账。需要采用更新的种子时，通过核心现有的文档种子采用流程明确更新对应文档。

## 独立交付

从本包目录执行以下命令，可生成包含全部人格资源的本地安装包：

```sh
npm pack --ignore-scripts
```

产物为 `asuna-yan-sui-0.2.0.tgz`。`private: true` 防止意外发布到公共 npm registry，不影响本地打包与交付。

已配置 Asuna 核心的 DSH Web 部署可使用其现有 DSH 命令安装该文件：

```sh
dsh plugin --profile <目标profile> add <交付包路径>
```

在目标 profile 的核心人格设置中选择 `yan-sui`，角色预设为 `asuna-yan-sui`。项目启动器管理的 profile 使用前述项目安装流程，以保持启动器记录的包选择一致。

## 验证范围

包的注册、资源完整性、参数模式、中文种子解析及提示词渲染可在不调用模型的情况下检查。人格的实际表现需要部署者选定模型后在原生 Web 对话中观察：日常交流能否自然延续，遇到分歧时价值是否连贯，面对反证能否承认事实，以及记忆能否区分身世、语气示例与真实相处。

这些观察关注选择与连续性，不以复述固定台词作为通过条件。结构与打包检查通过，只证明包可以正确装载，不等同于任何模型都能稳定呈现全部性格。
