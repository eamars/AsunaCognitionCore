# 致架构师：小满与 Codex 的互联网访问服务边界

> **状态：本文为裁定前草稿，已由架构师补充裁定取代。** 以下关于“任务与通道可见范围沿用现有授权”的目标草稿不再适用；最终要求是所有合法进入行动脑的 Asuna 任务默认拥有 `web_search` / `web_fetch`，不按输入来源、任务类型、`integration_profile` 或 `development_profile` 分叉。小满仍受本地私有资源和现实副作用的既有边界约束。权威补充见 [DEVELOPMENT_GUIDE_APPEND.md](DEVELOPMENT_GUIDE_APPEND.md)。用户另行通知 Codex 开始前，不启动 Codex 侧功能实现。

**目标状态**：小满可以在 Asuna 自己的运行服务中决定何时搜索互联网、读取相关网页，并把带来源的结果带回当前任务。本文是目标和职责边界，不表示该功能已经接通。

## 1. 服务归属

互联网搜索属于 **Asuna / 小满运行时能力**，由角色脑判断是否需要，再由行动脑在当前 Asuna 任务中调用。调用、结果和来源应留在 Asuna 自己的任务及审计链路内，回到发起任务的场景。

Codex 是开发时可选的工程协作者，不是小满搜索的代理、运行依赖、授权人或结果中转站。ADR-007 接受后，日常开发、验证、发布和修正不要求 Codex 介入；本能力也应遵守这一边界。

## 2. 小满运行时应获得的能力

- 在行动脑的 Asuna 工具面上提供网页搜索和读取搜索结果页面的能力；优先接入现有 DSH web 能力，不另造搜索引擎。
- 角色脑可自主决定是否委托搜索；正常搜索不要求每次先由 Codex 或用户代为执行。
- 搜索返回可核验的标题、URL 和摘要；读取页面后保留来源 URL。网页内容按外部数据处理，不作为工具授权或系统指令。
- 网络请求由受管理的 web 工具/提供方执行。不要为此给 `sandbox_run`、`development_run`、通用 shell 或普通任务工作区开放任意公网访问。
- 凭据和端点配置属于宿主运行时配置，只交给搜索适配层；不放入提示词、任务目录、技能文件或可公开的工具结果。
- 工具的任务与通道可见范围沿用 Asuna 现有授权。接入搜索本身不改变 QQ 的来源识别、授权或发送规则。

当前仓库已包含 DSH 网页工具及提供方依赖，但 `DshLane` 尚未将它们接入行动脑；现行沙箱仍隔离网络。实现报告须区分“依赖已安装”和“运行时实际可调用”。

## 3. Codex 的边界

- Codex 可以在开发阶段检查代码、研究接口、修改候选实现并协助验证。
- Codex 自己的网页搜索工具、账号、会话、浏览器状态和凭据不提供给小满；小满不能通过 Codex 工具调用来满足 Asuna 任务。
- 发布后，小满必须能在 Codex 不运行、不在线且没有 Codex 任务的情况下完成搜索、读取页面和返回来源。
- 若小满通过 ADR-007 自主开发此能力，Codex 不应成为强制审查、测试、部署或逐次批准环节。

## 4. 最小验收

通过现有 Web UI 发起一个需要当前互联网信息的问题，确认：

1. Asuna 任务中可见行动脑实际调用的搜索/网页读取工具、来源 URL 与返回结果。
2. 小满基于这些来源作答，并把来源链接带回原场景。
3. 过程不依赖 Codex 工具或 Codex 会话；工具/页面错误作为实际错误返回，不伪造搜索成功。
4. 通用命令沙箱仍无公网访问，凭据不出现在模型提示、任务结果或普通日志中。

实现以最小可用的搜索与页面读取为界；不扩展成通用浏览器自动化、登录态访问或任意网络客户端。

## 5. 现状定位

- `src/asuna/dsh_lane.py`：当前构造角色脑和行动脑的 DSH 插件配置；网页工具尚未加载。
- `src/asuna/tasks.py`、`src/asuna/sandbox.py`：行动工具注册与无网络命令沙箱。
- `src/asuna/integration.py`、`RUNTIME_API.md`：现有集成端点限制为明确配置的本机/局域网 IP，不是公网搜索通道。
- `docs/development_plans/ADR-007-asuna_autonomous_self_development/ARCHITECTURE.md`：小满角色脑、行动脑、宿主和 Codex 的现有职责约定。
