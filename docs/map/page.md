## `native_api`

[src/asuna/native_api.py](../../src/asuna/native_api.py)

Bounded, read-only projections for native DSH's Asuna memory tab.

- def `label`
- def `signed`
- def `ago_label` — How long ago, in the viewer's words (config.ago is the model-facing twin).
- def `kind_label` — Her persona's own word for a feeling (content), or the kind's id when it has none.
- def `paragraphs` — Parts the client concatenates: these items, a blank line between each (empty ones left out).
- def `mood_word`
- def `mood_line`
- def `event_line`
- def `mood_body`
- def `event_body`
- def `document_title`
- def `searchable` — The content text of a row (titles and excerpts may be labels: their content parameters count).
- def `plain` — One line of readable text: markdown markers and emphasis removed.
- class `NativeMemory`
  - `scene_title`
  - `timestamp`
  - `head_rows`
  - `document_rows` — Operator view of the persona's documents: every section, each with its visibility label.
  - `affect_ledger`
  - `affect_rows` — Owner view: her mood now, then the most recent things that moved her, each from its conversation.
  - `owner_view`
  - `idea_rows` — Her improvement-idea notebook and what she decided (ADR-011 §6.2), for the owner's view only.
  - `job_rows`
  - `page`
  - `detail`

## `native_cognition`

[src/asuna/native_cognition.py](../../src/asuna/native_cognition.py)

Read-only cognitive state coverage for the existing native Memory view.

- class `CognitionView`
  - `usage` — A key of the client's memory.usage words: whether the latest turn used this record.
  - `peer`
  - `supplements` — The platform identity saved with this person's latest message, when there is one.
  - `subject_name`
  - `account_title` — qq:<account> reads as `QQ · <account>` on the owner's page; a local id reads as itself.
