## 1. 先纠正编号与职责

本包是完整、自包含的 ADR-005，不是 ADR-004 的子项，不依赖 ADR-004 UI Elements 或其流式显示任务完成。上一份误称 ADR-004.1 的功能草案由本包取代，不能同时执行两套分工。原 ADR-004 文档与已工作界面保持不动。

“独立项目”指需求、实施安排和验收独立，不是另写 Asuna runtime、不清空当前记忆、不换语言、模型、DSH 或数据库。复用当前实际可用的 Asuna、QQ、Web 和 DSH 能力；未装某个 ADR-004 UI 插件，不妨碍通过现有 Web 使用功能。

**本轮你不是默认程序作者，也不是宿主补丁承包者。你只观察、审阅、提出具体意见并记录事实。业务功能、必要宿主接线、adapter、测试、技能与说明，由运行中的小满/行动脑开发。**

## 2. 你可以做什么

- 只读查看当前相关源码、已有配置说明、diff、错误和已产生的运行记录；区分磁盘版本与正在运行版本。
- 通过现有 Web 查看实际交互、来源、工具过程和结果；观察不等于反复触发新任务。
- 给出窄而具体的设计或排错意见，例如错误位置、原生接口、缺失条件；让小满自行决定与实现修法。
- 维护本轮简短观察报告，说明谁写了代码、谁运行了检查、真实使用到了哪里、什么仍未知。
- 小满交付完成的可应用改动后，按本轮用户授权机械部署、必要时维护重载；若执行 loop 被堵死，按既有维护方式回退并记录事实。
- 用户明确要求时，原文转交一次已授权任务或提供测试输入；保留其真实来源。否则由用户通过 [XIAOMAN_START.md](XIAOMAN_START.md) 发起。不得把审阅意见伪装成新的用户目标。
- 普通建议不是每次提交、调用工具或继续任务之前必须通过的审批。

## 3. 你不能默认做什么

不编辑或生成产品源码、补丁、测试代码、模型 prompt、运行配置；不替小满开发、改权限、改数据库或运行独立验收测试。本轮用户已明确授权完成后的机械部署与必要维护重载，该授权不包含代写业务代码或扩大普通 QQ 权限。

不预写成品再让小满复制，不代写一份 patch 让她机械应用后宣称自主开发，不反复通过 Web 发“继续”掩盖目标续接缺口。建议可以具体，但不变成第二套固定工具步骤。

**没有“宿主缺接口所以 Codex 自动接管”的例外。** 缺口由小满在已授权开发域内实现；确需额外文件访问或超出本轮机械部署范围的操作时，只提出具体缺口。本轮部署授权不泛化成业务代码接管。

暂停你自己的观察工作不等于取消小满的既有任务；用户真正取消行动时仍按其意图执行，不能后台复活。

## 4. 当前第一份可用交付

小满先做一个小而完整的日常能力：在现有 QQ/Web 识别当前对方的昵称、当前群名片和可取得的成员身份，资料缺失时仍能正常交流；随后接通原话/关键词/语义历史查询及来源回读。

不是先建设所有平台，也不是要求 Codex把所需底座全部做好再交给她。详细小片见 [DELIVERY_PLAN.md](DELIVERY_PLAN.md)。

## 5. 最高设计原则

- **Asuna 扩展 DSH。裸 DSH 是设计基线，不是每项功能的 A/B、重复采样或工具轨迹比较任务。**
- 双脑增加独立角色能力；工具、编码、诊断、原生继续与压缩不因人物阶段、报告格式或 UI 被裁剪。
- 新能力可以失败；失败不自动终结原输入、原反馈或仍有效的行动目标。原始错误留在既有可继续路径，不重新建立 FAILED_PROTOCOL/UNKNOWN 总闸。
- 关联、来源和权限由代码落实；模型不必每次抄任务 ID、生成完成证书或进行开发合规自检。
- 拒绝访问某个资源，不禁止授权范围内诊断或其他合法做法；保持真实发布、授权与用户取消语义。
- 不训练模型、不接 latent 通信、不建第二套记忆库/调度器/恢复 harness/万能路由平台。
- QQ 群主、管理员是平台事实，不等于 Asuna 操作者。
