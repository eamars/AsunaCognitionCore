## 设计缺口

实施前没有形成经架构师审阅的端到端系统方案，也未解决以下边界：

- QQ、Web UI 等入口分别是否允许图像输入，由谁授权，以及不支持或拒绝时如何反馈。
- 图像数据的会话绑定、访问范围、保存期限、大小限制、资源预算与模型能力检查。
- 角色脑和行动脑各自能接收什么图像信息，以及二者判断不一致时的证据记录、反馈路径和决策责任。

Codex 以“技术上可传递图片”为由先写实现，再补做局部探测；这不能替代上述产品与架构决策。
