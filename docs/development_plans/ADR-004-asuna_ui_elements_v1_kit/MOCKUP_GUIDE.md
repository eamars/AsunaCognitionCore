# Mockup Guide

The included mockup is a **directional UI reference**.
It defines:
- layout hierarchy
- bubble-first conversation design
- visible dual-brain trace region
- right-side inspector tabs and detail area

It does **not** define:
- backend field names
- exact runtime data shape
- exact CSS tokens
- exact component library choice

## Key visual points to preserve
- light theme
- simple sidebar
- large readable center conversation
- expandable internal trace for current reply
- inspector tabs on the right
- minimal decoration

## Key visual points not required
- exact timestamps
- exact sample texts
- exact fake memory items
- exact icon set
