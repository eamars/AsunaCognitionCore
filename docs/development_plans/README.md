# Development plans

This folder holds Asuna's architecture decision records (ADRs): what was decided, why, and plans not yet built. It is not the authority for current behaviour; that lives in [RUNTIME_API.md](../../RUNTIME_API.md), [docs/DEVELOPMENT.md](../DEVELOPMENT.md) and the source.

This index says only where each ADR stands. How it got there (installs, readings, Xiaoman's verdicts) is in the ADR's folder, in its `progress.md` when it has one. Large built ADRs keep only their decisions still in force, with the full text named by a git hash. Archived ADRs are removed from the tree; `git show <hash>:docs/development_plans/<folder>/<file>` (or `git log --all -- docs/development_plans/<folder>`) brings any of them back.

Status: **Active**, an ongoing routine. **Decided**, accepted and not built. **Open**, built and installed, with the part under "Left" still to do. **Built**, built and installed, nothing left. **Archived**, removed from the tree.
