# ADR-008 修订案：重启后等待明确续接

批准日期：2026-10-04。真实模型测试发现旧任务反馈会在重启后再次委托自修复；用户选择“等待我在现有本地聊天中明确要求继续”。

有效但未完成的旧行动，以及尚未处理完成的行动反馈，重启后暂停。保留任务身份、原生执行上下文、已产生的结果、工具回执与失败记录，不自动调用两脑处理旧反馈，也不自动再次执行。已经完成的反馈只核对持久状态，不重新生成。

操作者在现有本地会话明确要求继续后，角色通过新的决策续接原任务的执行关联；新行动先核实已有结果，不能盲目重做没有回执的操作。普通聊天、内部自我开发机会及旧反馈不构成续接授权。明确取消的旧任务不得因此复活。

取消、修订或重启暂停发生在反馈处理期间时，已经发生的模型输出保留为内部记录；旧反馈不得继续产生后续决策、工具授权或公开回复。取消后不得用推理前读取的旧版本覆盖新任务状态。

本修订仅改变恢复与授权边界。沿用现有本地输入区和 DSH 原生记录展示，不批准或新增 UI 控件。完成情况以当前实现及运行证据为准。
