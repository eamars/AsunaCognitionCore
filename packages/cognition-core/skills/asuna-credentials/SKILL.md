# asuna-credentials

与人格无关的核心技能，随认知核发布。

## 一句话

值只出现一次——收进保险箱的那一下。之后只用名字。
值不许出现在发出去的话里——群、私聊、报告、日志；要指它就说保险箱名字。

## 收（角色脑，只在家里）

- 有人在家里把密码、口令、令牌、账号交给你：用 `credential` 的 `keep` 收进保险箱。
  - `name`：短名，小写字母、数字、连字符（如 `solar-portal`）。
  - `note`：一句话说它是干什么的、授权到哪儿（如「主人的光伏门户账号，只读，只看自家站点」）。不写值。
  - `env`：环境变量名（大写）→ 值，最多 6 个，如 `{"PORTAL_EMAIL": "…", "PORTAL_PASSWORD": "…"}`。
- 收进去以后谁都看不到值：你看不到，行动脑也看不到。家里的回合会列出 `credentials_from_program`：只有名字、用途和变量名。
- 换了密码：用同一个名字再 `keep` 一次。不用了：`drop`。
- 群里、别人的私聊里没有保险箱。那里有人给你密码，不接、不用，回家跟主人说。

## 用（行动脑，只在从家里来的任务里）

- 交代里写「用保险箱里的 `solar-portal`」，不写值。
- 行动脑跑命令：`sandbox_run` 加 `credentials: ["solar-portal"]`。这些环境变量只在这一条命令里有。
- 脚本从环境变量读：`os.environ['PORTAL_PASSWORD']`。
- 程序会把任何工具结果、报告、交代里出现的保险箱里的密码类值（变量名带 pass、token、secret、key 的）换成「[凭据已隐藏]」；用户名、邮箱、主机这些照原样留着。这是兜底，不是许可：
  - 不要 `print` 值、不要把值写进文件、脚本、笔记、报告、想法本、文档、技能。
  - 登录响应、cookie、令牌也是凭据：不落盘；非要落盘的会话文件，任务做完就删。
  - 别把值放进 URL 的查询串、命令行参数（命令行会被记录），用请求体或环境变量。
- 登录只试一次。失败就停，把状态码和响应报回来，不改大小写重试——很多服务连错几次就锁号。

## 用别人给的账号：只看授权的那一份

账号能看到的，常常比你被授权看的多。尤其是员工、管理员、安装商账号：它们能看到别的客户、别的站点、内部后台。

- 只访问授权给你的那个对象（那个站点、那个仓库、那个邮箱）。按它的 id 直接取，不要搜索、不要列表、不要「列出全部再挑」。
- 走普通用户那一侧的页面和接口；带 `admin`、`eeadmin`、`manage`、`internal`、`staff` 一类字样的路径不碰，被重定向到后台就停。
- 不小心拿到了别人的数据：不读、不引用、不存；已经落盘的立刻删掉，并在报告里如实说一句。
- 只读的账号只发读请求；不调用 logout（可能把同一账号的另一个会话踢下线）。

## 探活 → 重取／重登 → 回写：标准流程

用于要用保险箱凭据登录的任务，以及账号自治的站点技能（登录态文件＋站点脚本）。这是流程文档，不是授权：没有的凭据不凑，别人给的账号只看授权的那一份。顺序固定，一次只走一条：

1. **探活（只读、不消耗）**：先拿现有登录态打一个只读探活接口（用哪个、怎么判死活，写在该站点技能里）。活——直接取数，不重登。
2. **探活失败，按失败的形状走对应的一步**（按保险箱里那一项的类型判，类型看它的 `note` 和环境变量名的样子，不在这里列谁的号）：
   - **账号＋密码类**（邮箱／手机号加密码）：登录态死了——走该站点技能写的重登流程，在一条 `sandbox_run` 里带 `credentials` 名字、用环境变量。重登预算每次一到两次，失败即停，报状态码和脱敏后的响应，不改大小写重试。
   - **密钥／令牌类**（client id＋ secret、consumer key＋ secret、access token＋ secret）：探活＝一次只读的身份接口。401／403 没有「重登」这一步——令牌是开发者后台签发的，我自己重取不了：停，报「哪一项、哪个码」，找主人重发。
   - **机器登录类**（主机／用户／口令）：探活＝只读连接＋无副作用命令。连不上／被拒：停，不试第二组口令，找主人（对方有没有同意、口令换没换都不是我能判的）。
   - **环境变量缺失或为空**（脚本报 KeyError／空串；任务里的 `credentials_from_program` 清单没有这个名字、或变量名对不上）：不是我能补的，停，报「缺哪个名字、缺哪个变量」，找主人（只有他能 `keep`）。
   - **值在，但站点拒**（密码错、账号冻结、要验证码／短信／新的风控字样）：停，不重试，报 HTTP 码＋脱敏后的 body，找主人。站点技能里已记录、可以自动过的形状（如验证滑块）按那条技能走，记录之外的新形状即停。
   - **要人参与的一步**（比如扫码登录）：通知主人，并把形状给全（有效期、码或链接落在哪个绝对路径），不空等。
   - **凭据到期**（保险箱 `note` 写了到期约定的）：未到期不提前探；到期前后探活失败先看 `note`，确是到期就找主人换，不重试。
3. **重取／重登成功后回写**：把新登录态写回登录态文件（站点技能约定的位置；只待在那个文件里，不打印值、不进报告、不进别的文件），然后用同一个探活接口**再探一次**确认活，再取数。回写成功 ≠ 可用，以复探为准。
4. **报告写**：探活的码、走了哪一步、重登几次、回写了没有、复探的码；不写任何值。
5. **何时找主人（汇总）**：变量缺失；值被站点拒；要人参与的验证；凭据到期；密钥令牌类 401／403；重登预算用完仍失败。其它情形（纯登录态过期、站点技能写了怎么重登）自己走完，不打扰。

## 探针打印前递归脱敏

**规矩**：探测脚本（读配置、读集成设置、探端点、登录响应）凡要把 dict／JSON 打印出来，**打印前先递归脱敏**：遍历所有层级的 dict 和 list，键名命中 token／secret／password／key／cookie／auth／credential 一类（大小写不分）的值一律换成占位。不要对 `json.dumps` 的结果做正则、只挡顶层的 `"token"`：嵌套 dict 里的 token 会漏（实例：一次配置探针只挡了顶层键，嵌套段里的 token 整串进了工具记录）。程序的「凭据已隐藏」兜底只替换保险箱里登记过的值，配置里没登记的值不在兜底之内。

最小实现（最小嵌套样例跑过：嵌套在列表里的 `Password`、两层下的 `token`、名字里带 `key` 的整棵子树都被打码，普通键原样保留）：

```python
import json, re
SENSITIVE = re.compile(r"(token|secret|pass(word|wd)?|key|cookie|auth|credential)", re.I)

def redact(x):
    if isinstance(x, dict):
        return {k: ("[已打码]" if SENSITIVE.search(str(k)) else redact(v)) for k, v in x.items()}
    if isinstance(x, (list, tuple)):
        return [redact(i) for i in x]
    return x

print(json.dumps(redact(cfg), ensure_ascii=False, indent=1))   # 永远打印 redact(...) 的结果，不打印 cfg 本身
```

键名命中就整个值（含子树）替换、不再往下递归。按键名挡不住「值里夹带的秘密」（URL 查询串、整段响应正文）：那类只报状态码、长度、键名，不打印正文。

## 收口：读过「带凭据的文件」的任务，交回前跑一次全树值扫描

凡是读过带凭据的文件（登录态文件、配置、别人给的账号文件）的任务，交回报告前跑一次派生式全树值扫描：防的是「删了原件但值还在别的笔记里」和「值被我抄进报告」两类事故。

1. **从原文件用规则现取值**：按文件的形状（键名命中上面「探针打印前递归脱敏」那一类的值，再加那一项保险箱登记的环境变量值）在这一条命令里现取到内存里，不手抄、不写进脚本。“像密码的近词”（不足 12 字符的口令、账号 id、主机）也一并取。
2. **字节级多模式扫 /task 全树**（不是只扫报告）：值不是纯 ASCII 时也要按字节匹配，不依赖文本解码。
3. **报告里只出「sha 前 12 位＋路径＋命中行数」**，值永远不落盘、不进报告、不打印。
4. **值表不跨命令**：值表如需落文件，只能在这一条命令里建、用、删（临时目录一条命令就回收，设在 /task 里的不算临时），最后一步自删、**再复扫一次证命中为 0**。报告里写清：扫了哪棵树、几个模式、复扫的读数。
5. 扫出命中：不读、不引用，删掉那一处再扫，并在报告里如实说一句（写文件路径和行数，不写值）。

这一步不等于已经有并跑过的脚本：最小形状每次现写。“将来做成现成脚本”是想法，这里不先应承。

## 写技能时

**账号事实（谁的号、什么钥匙：账号名、手机号、邮箱、群号、站点 id、主机、某个保险箱名字对着谁的账号）不进技能正文**。技能只写「从哪读」：保险箱名字由任务清单现给、登录态文件路径约定、本机私有文件。已经写进正文的，转到该在的账：那个账号的保险箱 `note`、角色脑自己的身份／账本文档（用 `write_document` 写）、本机私有文件。

技能里写方法，不写凭据：「从 `credentials: [solar-portal]` 读 `PORTAL_PASSWORD`」，不写账号、密码、个人信息。发布前的个人数据扫描会拦，但别指望它替你拦。
